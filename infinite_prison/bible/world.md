# 世界观设定

## 核心设定

1. **无限副本是监狱**：世界上存在一个叫"渊"的系统。它不是在给玩家发福利——它在运行一座监狱。每一个副本都是一间牢房，里面关着某个"不可言说之物"——被封印的上古存在、失控的因果法则、从现实裂缝中渗进来的东西。玩家进入副本、完成任务、获得奖励——他们以为自己在通关，实际上每一次"通关"都在给牢房上锁。他们不是玩家，是不知情的狱卒。

2. **狱警**：主角是"渊"雇佣的狱警。和普通玩家不同，狱警能看见副本的底层代码——每个副本的真实结构、封印的完整度、被关在里面的东西的活跃程度。狱警的工作不是通关，是巡视：检查封印是否松动、处理被"污染"的玩家、修复副本中的异常。狱警没有面板、没有技能、没有奖励——只有一把能看见真相的"钥匙"。

3. **封印体系**：副本按封印深度分为九层。前五层是普通副本——恐怖病院、赛博废墟、镜中公寓——封印的是小型异常。第六到第八层关着的是"法则级"存在——时间扭曲体、因果吞噬者、记忆瘟疫。第九层只有一个牢房。门上没有编号，只有一个名字——但目前没人看得清那是什么字。

4. **污染与回收**：在副本里死亡的玩家不会真正消失。他们的意识会被副本中的"不可说之物"污染，变成副本的一部分——新的怪物、新的规则、新的陷阱。狱警的另一个任务是回收这些被污染的"残留物"。但回收不是杀死——是把它们从副本里带出来。带出来之后会发生什么，系统没有说明。

## 世界观谜题（贯穿全书的暗线）

- 第九层牢房里关的是谁？封印上刻的名字到底是谁的？
- 为什么主角能看见底层代码？其他狱警看不到吗？
- "渊"到底是什么——一个系统？一个存在？还是一座监狱本身？
- 那些被回收的"残留物"——它们去了哪里？

## 文风样本

顾渊站在副本入口，看着面前那面只有他能看见的墙。

那是一道透明的屏障——对玩家来说不存在，对"里面那个东西"来说坚不可摧。墙上嵌着密密麻麻的金色符文，每一道符文都在微微发着光，像是一台上锁的机器还在运转。他举起右手，手心里浮现出一枚巴掌大的青铜钥匙——这是"渊"给他的唯一一件东西。

"底层代码，读取。"

符文在他眼前展开，变成只有他能看懂的三行字——

牢房编号：L-017
封印完整度：78%（持续下降中）
被封印物活跃度：正在上升

顾渊把钥匙按在屏障上。符文裂开一道口子，刚好容他侧身进入。在他身后，一群正在排队进入副本的玩家兴奋地讨论着奖励和技能——他们不知道门后面不是宝藏，是一座需要随时检查是否松动的牢房。

钥匙微微一颤。他知道里面那个东西已经感觉到他来了。

"又见面了，狱警先生。"

顾渊没有回答。他跨进了门。

门在他身后合上。符文重新亮起。封印完整度显示为79%——他每次进入副本，都会用自己的"存在"来加固封印。这是他作为狱警的代价：每巡视一个副本，他身上就多一道锁。

没人告诉过他，当锁多到无法承受时会发生什么。

但他已经开始数了。
